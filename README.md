# Thanima: stockist landing page (concept)

A landing page for Thanima, a concept ragi-and-whey protein drink brand from Kerala, written for gym owners, health stores and distributors deciding whether to stock it.

**Live page:** https://sachinrajeevcodes.github.io/thanima/

## What I did
- Wrote the copy: the positioning, three reasons to stock it, how stocking works, and buyer FAQs
- Designed the page and created the product imagery with AI, using a reference-locked workflow so the pack stays identical across scenes
- Wrote the search title and meta description for trade buyers

Full case study: https://www.behance.net/sachinrajeev4

*Concept work by Sachin Rajeev, 2026. Thanima is not a registered brand and no product is on sale. Bracketed items on the page are placeholders.*
